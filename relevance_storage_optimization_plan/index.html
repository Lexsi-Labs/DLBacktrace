Relevance Storage Optimization Plan¶

DLBacktrace Node-Level Relevance Per-Step Storage Strategy¶

Document Version: 1.0
Date: December 17, 2025
Status: Planning Phase

1. Problem Statement¶

Current Situation¶

  • Storage per token: 2.75 GB
  • Tokens per sample: 5 tokens
  • Total per sample: 13.75 GB
  • Dataset size: 290 samples
  • Total required: ~4 TB

Root Cause Analysis¶

Using PyTorch Export + DLBacktrace with LRP-style relevance attribution, we store: - All computation graph nodes per generation step - Full vocabulary relevance (151,936 tokens) for each sequence position - All intermediate layers (embeddings, attention, MLP, normalization) - Float16 compression already applied (50% reduction from float32)

Critical Constraint¶

Goal: Maintain node-level granularity for all computation graph nodes per generation step while reducing storage by 10-100x.

3. Detailed Optimization Techniques¶

3.1 Sparse Tensor Compression (PyTorch Native)¶

Reference: PyTorch Sparse Tensors Documentation

3.1.1 CSR (Compressed Sparse Row) Format¶

When to use: - Relevance matrices with >90% zero values - After threshold-based pruning (e.g., keep only top 1% of relevance scores)

PyTorch Implementation: 

def convert_to_sparse_csr(relevance_tensor: torch.Tensor, threshold: float = 1e-4) -> torch.Tensor:
    """
    Convert dense relevance tensor to CSR sparse format.

    Args:
        relevance_tensor: Shape (batch, seq_len, vocab_size) or (seq_len, vocab_size)
        threshold: Values below this are zeroed out

    Returns:
        Sparse CSR tensor with significantly reduced storage
    """
    # Apply threshold to create sparsity
    mask = torch.abs(relevance_tensor) > threshold
    sparse_tensor = relevance_tensor * mask

    # Convert to CSR format (works with 2D tensors)
    if sparse_tensor.dim() == 3:
        # Process batch dimension separately
        sparse_list = []
        for i in range(sparse_tensor.size(0)):
            sparse_2d = sparse_tensor[i].to_sparse_csr()
            sparse_list.append(sparse_2d)
        return sparse_list
    else:
        return sparse_tensor.to_sparse_csr()

Expected Compression: - Threshold 1e-4: 95-98% sparsity → 20-50x reduction - Threshold 1e-3: 98-99% sparsity → 50-100x reduction

Trade-offs: - ✅ Lossless compression of sparse data - ✅ Native PyTorch support - ✅ Can reconstruct full tensor on demand - ⚠️ Requires threshold tuning per use case - ⚠️ CPU-only for CSR operations (as of PyTorch 2.9)

3.2 Top-K Relevance Pruning¶

Insight: For most interpretability tasks, only the highest-relevance tokens matter.

3.2.1 Vocabulary-Level Top-K¶

def prune_topk_vocabulary(
    relevance_tensor: torch.Tensor, 
    k: int = 100,
    keep_indices: bool = True
) -> Dict[str, torch.Tensor]:
    """
    Keep only top-K tokens per sequence position.

    Args:
        relevance_tensor: Shape (batch, seq_len, vocab_size)
        k: Number of top tokens to retain (default: 100)
        keep_indices: Store token indices for reconstruction

    Returns:
        Dict with 'values', 'indices', 'shape' for sparse storage
    """
    batch, seq_len, vocab_size = relevance_tensor.shape

    # Get top-K values and indices per position
    topk_values, topk_indices = torch.topk(
        relevance_tensor, 
        k=min(k, vocab_size), 
        dim=-1, 
        largest=True, 
        sorted=True
    )

    # Store in compressed format
    return {
        'values': topk_values.to(dtype=torch.float16),      # (batch, seq_len, k)
        'indices': topk_indices.to(dtype=torch.int32),      # (batch, seq_len, k)
        'shape': relevance_tensor.shape,
        'k': k,
    }

Memory Calculation: - Before: 1 × 32 × 151,936 × 2 bytes = 9.3 MB (one step, float16) - After (k=100): 1 × 32 × 100 × (2+4) bytes = 19.2 KB (values + indices) - Compression ratio: 484x reduction

Use Cases: - Attention head analysis (k=50-100) - Token attribution (k=20-50) - Layer importance (k=10-20)

3.3 Quantization to Int8/Int4¶

Reference: PyTorch Quantization

3.3.1 Dynamic Quantization¶

import torch.ao.quantization as quantization

def quantize_relevance_int8(relevance_tensor: torch.Tensor) -> Dict[str, Any]:
    """
    Quantize float16 relevance to int8 with scale/zero_point tracking.

    Args:
        relevance_tensor: Float16 tensor

    Returns:
        Dict with quantized data + dequantization parameters
    """
    # Calculate quantization parameters
    r_min = relevance_tensor.min()
    r_max = relevance_tensor.max()

    # Compute scale and zero point for int8 range [-128, 127]
    scale = (r_max - r_min) / 255.0
    zero_point = -128 - (r_min / scale).round()

    # Quantize
    quantized = ((relevance_tensor / scale) + zero_point).round().clamp(-128, 127).to(torch.int8)

    return {
        'data': quantized,
        'scale': scale.item(),
        'zero_point': zero_point.item(),
        'shape': relevance_tensor.shape,
    }

def dequantize_relevance_int8(quantized_dict: Dict[str, Any]) -> torch.Tensor:
    """Reconstruct float16 tensor from quantized int8."""
    data = quantized_dict['data'].to(torch.float32)
    scale = quantized_dict['scale']
    zero_point = quantized_dict['zero_point']

    return ((data - zero_point) * scale).to(torch.float16)

Memory Calculation: - Float16: 2 bytes per value - Int8: 1 byte per value + 8 bytes (scale + zero_point) - Compression ratio: ~2x reduction (plus float16's existing 2x)

Accuracy Analysis: - Int8 quantization: ~0.39% relative error - Acceptable for most interpretability tasks - Preserves ranking of relevance scores

3.4 Hierarchical Storage with Layer Sampling¶

Strategy: Not all layers need full storage - sample strategically.

class HierarchicalRelevanceStorage:
    """
    Store full relevance for critical layers, summaries for others.
    """

    def __init__(self, num_layers: int, critical_layers: List[int] = None):
        """
        Args:
            num_layers: Total transformer layers
            critical_layers: Layers to store fully (default: [0, mid, -1])
        """
        if critical_layers is None:
            mid = num_layers // 2
            critical_layers = [0, mid, num_layers - 1]

        self.num_layers = num_layers
        self.critical_layers = set(critical_layers)

    def store_layer_relevance(
        self, 
        layer_idx: int, 
        relevance: torch.Tensor,
        mode: str = "auto"
    ) -> Dict[str, Any]:
        """
        Store relevance with strategy based on layer importance.

        Storage strategies:
        - Critical layers: Full sparse tensor (top-K=1000)
        - Intermediate layers: Top-K=100
        - Non-critical: Statistical summary only
        """
        if layer_idx in self.critical_layers:
            # Full storage with moderate pruning
            return prune_topk_vocabulary(relevance, k=1000)

        elif layer_idx % 3 == 0:  # Every 3rd layer
            # Compressed storage
            return prune_topk_vocabulary(relevance, k=100)

        else:
            # Summary statistics only
            return {
                'mean': relevance.mean(dim=-1),
                'std': relevance.std(dim=-1),
                'max': relevance.max(dim=-1).values,
                'layer_idx': layer_idx,
                'storage_mode': 'summary',
            }

Memory Savings: - Qwen3-0.6B: 28 layers - Critical layers (3): Full storage @ 20 KB each = 60 KB - Sampled layers (9): Compressed @ 2 KB each = 18 KB - Summary layers (16): Stats @ 0.5 KB each = 8 KB - Total per step: ~86 KB vs 2.75 GB = 32,000x reduction

3.5 Incremental Compression with Memory-Mapped Files¶

Reference: PyTorch Distributed Checkpoint

import mmap
import numpy as np
from pathlib import Path

class MemoryMappedRelevanceStore:
    """
    Memory-mapped storage for streaming relevance data.
    """

    def __init__(self, cache_dir: Path, max_tokens: int = 10):
        self.cache_dir = Path(cache_dir)
        self.cache_dir.mkdir(parents=True, exist_ok=True)
        self.max_tokens = max_tokens
        self.metadata = []

    def write_step(
        self, 
        step_idx: int, 
        relevance_dict: Dict[str, torch.Tensor],
        compression: str = "zstd"
    ):
        """
        Write one generation step with compression.

        Args:
            step_idx: Generation step number
            relevance_dict: Node relevances for this step
            compression: "none", "gzip", "zstd" (recommended)
        """
        step_file = self.cache_dir / f"step_{step_idx:05d}.pt.zst"

        # Apply sparse conversion before saving
        compressed_dict = {}
        for node_name, tensor in relevance_dict.items():
            if tensor.numel() > 10000:  # Large tensors
                compressed_dict[node_name] = convert_to_sparse_csr(tensor, threshold=1e-4)
            else:
                compressed_dict[node_name] = tensor.to(dtype=torch.float16)

        # Save with torch.save + external compression
        torch.save(compressed_dict, step_file)

        # Compress with zstd (better than gzip for tensor data)
        if compression == "zstd":
            import zstandard as zstd
            with open(step_file.with_suffix('.pt'), 'rb') as f_in:
                with open(step_file, 'wb') as f_out:
                    cctx = zstd.ZstdCompressor(level=3)
                    cctx.copy_stream(f_in, f_out)
            step_file.with_suffix('.pt').unlink()  # Remove uncompressed

        self.metadata.append({
            'step': step_idx,
            'file': str(step_file),
            'size_bytes': step_file.stat().st_size,
        })

    def read_step_lazy(self, step_idx: int) -> Dict[str, torch.Tensor]:
        """Lazy load one step from disk."""
        step_file = self.cache_dir / f"step_{step_idx:05d}.pt.zst"

        # Decompress and load
        import zstandard as zstd
        dctx = zstd.ZstdDecompressor()
        with open(step_file, 'rb') as f:
            decompressed = dctx.decompress(f.read())

        import io
        buffer = io.BytesIO(decompressed)
        return torch.load(buffer)

Expected Compression: - Zstandard level 3: 3-5x additional reduction on sparse tensors - Memory-mapped loading: Load only requested steps - Combined with sparse CSR: 100-500x total reduction possible

6.2 Relevance Quality Preservation¶

def validate_relevance_quality(
    original: torch.Tensor, 
    reconstructed: torch.Tensor
) -> Dict[str, float]:
    """
    Measure quality preservation after compression/decompression.
    """
    # Ranking consistency (most important for interpretability)
    topk_orig = torch.topk(original, k=100, dim=-1).indices
    topk_recon = torch.topk(reconstructed, k=100, dim=-1).indices
    ranking_overlap = (topk_orig == topk_recon).float().mean()

    # Value accuracy
    mse = torch.nn.functional.mse_loss(original, reconstructed)
    relative_error = (torch.abs(original - reconstructed) / (torch.abs(original) + 1e-8)).mean()

    # Spearman correlation
    from scipy.stats import spearmanr
    flat_orig = original.flatten().cpu().numpy()
    flat_recon = reconstructed.flatten().cpu().numpy()
    correlation, _ = spearmanr(flat_orig, flat_recon)

    return {
        'topk_ranking_overlap': ranking_overlap.item(),
        'mse': mse.item(),
        'relative_error': relative_error.item(),
        'spearman_correlation': correlation,
    }

Acceptance Criteria: - Top-K overlap: >95% (critical for interpretability) - Spearman correlation: >0.95 - Relative error: <5%

class CompressionProfiler:
    """Track compression performance in production."""

    def __init__(self):
        self.metrics = {
            'compression_time': [],
            'decompression_time': [],
            'compression_ratio': [],
            'quality_metrics': [],
        }

    def log_compression(self, original_size, compressed_size, duration, quality):
        self.metrics['compression_time'].append(duration)
        self.metrics['compression_ratio'].append(original_size / compressed_size)
        self.metrics['quality_metrics'].append(quality)

    def report(self):
        return {
            'avg_compression_time': np.mean(self.metrics['compression_time']),
            'avg_compression_ratio': np.mean(self.metrics['compression_ratio']),
            'avg_quality_score': np.mean([q['topk_ranking_overlap'] 
                                          for q in self.metrics['quality_metrics']]),
        }

A.1 Modify _compress_relevance_tree()¶

File: dl_backtrace/pytorch_backtrace/dlbacktrace/core/dlb_auto_sampler.py

def _compress_relevance_tree(
    self, 
    rel_dict, 
    target_dtype, 
    move_to_cpu: bool,
    # NEW PARAMETERS
    topk: Optional[int] = None,
    sparse_threshold: Optional[float] = None,
    compression_preset: str = "float16",
):
    """
    Compress relevance tree with multiple strategies.

    Args:
        topk: Keep only top-K tokens per position (None = no pruning)
        sparse_threshold: Convert to sparse CSR if sparsity > threshold
        compression_preset: "float16" | "int8" | "balanced" | "minimal"
    """
    if rel_dict is None:
        return None

    def compress_tensor(tensor):
        # Existing float16/dtype conversion
        tensor = tensor.to(dtype=target_dtype)

        # NEW: Top-K pruning for vocabulary dimension
        if topk is not None and tensor.dim() >= 2 and tensor.size(-1) > topk:
            tensor = prune_topk_vocabulary(tensor, k=topk)

        # NEW: Sparse conversion for high-sparsity tensors
        if sparse_threshold is not None:
            sparsity = (torch.abs(tensor) < sparse_threshold).float().mean()
            if sparsity > 0.90:  # >90% zeros
                tensor = convert_to_sparse_csr(tensor, threshold=sparse_threshold)

        # Move to CPU if requested
        if move_to_cpu:
            tensor = tensor.cpu()

        return tensor

    # Apply compression recursively
    return {k: compress_tensor(v) if torch.is_tensor(v) else v 
            for k, v in rel_dict.items()}

        decompression_time = time.perf_counter() - start

        # Validate quality
        quality = validate_relevance_quality(

        results['samples'].append({
            'sample_id': i,
            'original_size_mb': original_size / 1024**2,
            'compressed_size_mb': compressed_size / 1024**2,
            'compression_ratio': original_size / compressed_size,
            'compression_time_s': compression_time,
            'decompression_time_s': decompression_time,
            'quality': quality,
        })

        compressed_path.unlink()  # Clean up

    # Aggregate results
    avg_ratio = sum(s['compression_ratio'] for s in results['samples']) / num_samples
    avg_quality = sum(s['quality']['topk_ranking_overlap'] for s in results['samples']) / num_samples

    print(f"\n{'='*60}")
    print(f"Preset: {preset}")
    print(f"Average Compression Ratio: {avg_ratio:.1f}x")
    print(f"Average Quality (Top-K Overlap): {avg_quality:.2%}")
    print(f"Average Compression Time: {sum(s['compression_time_s'] for s in results['samples'])/num_samples:.2f}s")
    print(f"{'='*60}\n")

    return results

                       default="balanced")
    parser.add_argument("--samples", type=int, default=10)
    args = parser.parse_args()
